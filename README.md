# Сборка
Из корня репозитория
```
mkdir build
cd build
cmake ..
make all
```

# Запуск и остановка
## Сервер
Из корня репозитория, после сборки, запуск командой
```
build/bin/server261028a
```
После запуска сервер работает в бесконечном цикле, пока не послать сигнал SIGINT (Ctrl+C в bash терминале или `kill`)

## Клиент
Из корня репозитория, после сборки, запуск командой
```
build/bin/client261028a
```
После запуска клиент отправляет один пакет на localhost и завершает свою работу.
